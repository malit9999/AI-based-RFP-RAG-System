## 2. 프롬프트 개선 실험 (prom_01 ~ prom_09)

### 2.1 버전별 변경 이력

| 버전          | 핵심 변경                                                | 효과                  |
| ------------- | -------------------------------------------------------- | --------------------- |
| v1            | 역할 + Guardrail + 출처 명시                             | Baseline              |
| v2            | CoT +**답변/근거/출처** 구조화 + Self-Correction   | 답변 구조 안정화      |
| v3~v6         | 시스템 프롬프트 세부 조정                                | 점진적 개선           |
| **v7e** | Deterministic Answer + TYPO_REPLACEMENTS + Evidence Card | 금액/기간 정확도 향상 |

### 2.2 Deterministic Answer 로직 (v7e 핵심)

LLM 호출 없이 규칙 기반으로 직접 답변을 생성하여 정확도와 속도를 동시에 개선하였다.

| 유형                | 발동 조건                  | 처리 방식                  |
| ------------------- | -------------------------- | -------------------------- |
| 단순 예산           | 금액 키워드 + 단일 사업    | 청크에서 핵심 금액 추출    |
| 금액 + 비율         | %, 공제, 차감 키워드       | 순차 차감 계산             |
| 다중 금액 합산/차액 | 금액 2개 이상 질문 내 포함 | 질문 제시 수치로 직접 계산 |
| 기간                | 개월, 기간 키워드          | 개월 수 직접 추출          |

### 2.3 Query Re-writing (ConversationManagerV2)

모호한 지시어(`그것`, `해당`, `앞서` 등) 감지 시 독립 질문으로 재작성한다.

| 지표                    | V1 (재작성 없음) | V2 (재작성 적용)      |
| ----------------------- | ---------------- | --------------------- |
| Type B answer_relevancy | 0.28             | **0.53** (+89%) |

## 5. 부가 실험 및 연구

### 5.1 데이터 파이프라인 분석

- HWP 파싱 이슈 발견: Mac에서 olefile이 garbage 문자 대량 생성
- 해결: hwp5txt primary + 바이너리 파서 표 추출 병행

### 5.2 ChromaDB 플랫폼 이식

- 문제: Windows 빌드 HNSW 바이너리가 Mac M4(ARM)에서 로드 불가
- 해결: Windows에서 벡터 추출(npy) → Mac에서 재삽입

### 5.3 Tool Calling 도입

| 도구                | 기능                 |
| ------------------- | -------------------- |
| calculate           | 수식 계산            |
